# 写稿助手 Ghost Writer

输入句末标点后，写稿助手会请求 OpenAI 兼容的 LLM 预测你最可能写的下一句，并以灰色幽灵文字显示在光标后面，按 `Tab` 采纳。

> **所有文档默认关闭。** 填好 API Key 后，还需要在想用的文档里逐个开启（见下文）。未开启的文档不会有任何提示，也不会发出请求。

## 使用

### 开启

- **按文档开关（默认关闭）**，以下任一方式都可以，状态按文档分别记住：
  - 编辑器面包屑栏上的幽灵按钮（开启时高亮）
  - 文档标题图标菜单 →「写稿助手：本文档已开启 / 未开启」
  - 命令「写稿助手：本文档开关」，默认没有快捷键，可在 设置 → 快捷键 的插件分组中自行绑定
- **全局开关**：`Alt+Shift+G`（或插件设置中的「启用」）。它在所有文档里统一开关预测，不改变各文档的开关状态。

### 写作时

- 输入触发标点（默认 `，。！？；：,.!?;:`）并停顿超过防抖延迟（默认 400 毫秒）后请求预测。请求需要同时满足：
  - 光标在块末尾
  - 不在输入法组字过程中
  - 编辑器不是只读状态
- 代码块、公式块、HTML 块、表格、数据库、iframe、挂件、视频、音频块以及嵌入块内不会触发。
- `Tab` 采纳。采纳后会接着预测下一句，连续按 `Tab` 即可连续写作。
- `Esc` 丢弃。继续输入、点击、移动光标、滚动或焦点离开编辑器也会让建议消失。
- 思源的提示菜单（`/`、`[[`、`((`、`:` 等）打开时，`Tab` / `Esc` 交给思源处理，此时也不会发起预测。
- 显示建议时，`Tab` 优先用于采纳，不会缩进列表项。`Shift+Tab`、`Ctrl+Tab` 不会被拦截。
- 幽灵文字是浮层，采纳之前不会写入文档，也不影响撤销栈。
- 采纳的文字按原文插入：`*`、`$`、`((` 等 Markdown 字符会被转义，显示为普通文字，导出原始 Markdown 时可以看到反斜杠。
- 仅支持桌面端（桌面应用、桌面新窗口、桌面浏览器），移动端和发布服务页面不加载本插件。

## 配置

思源 → 设置 → 集市 → 已下载 → 写稿助手 → ⚙：

| 设置项 | 说明 |
|---|---|
| API 地址 | OpenAI 兼容地址，如 `https://api.deepseek.com/v1`。必须以 `http://` 或 `https://` 开头，误粘贴的 `/chat/completions` 后缀会被自动去掉。地址无效时会提示错误，并保留原值。默认 `https://api.deepseek.com` |
| API Key | 必填，未填写时不会发出任何请求。不需要 Key 的本地服务（Ollama、LM Studio 等）也要随便填一个值，如 `local` |
| 模型 | 默认 `deepseek-flash` |
| 防抖延迟（毫秒） | 100–60000，默认 400 |
| 最大上下文字数 | 发送多少前文，200–1000000，默认 1500 |
| 触发标点 | 输入这些字符后触发预测 |
| 通过内核 forwardProxy 转发 | 见 [CORS 与 forwardProxy](#cors-与-forwardproxy) |
| 额外请求参数（JSON） | 见 [额外请求参数](#额外请求参数) |
| 温度 | 0–2，越低越贴近原文，越高越发散，默认 0.7 |
| 系统提示词 / 用户消息模板 | 见 [自定义提示词](#自定义提示词) |

数字项留空或无效时使用默认值，超出范围时取最近的边界值。

### 额外请求参数

这里填写一个 JSON 对象，会合并进 chat completions 请求体，主要用来关闭思考模式（一句话的预测开思考既慢又费 token）。

- 可以覆盖 `temperature`、`max_tokens`（默认 80），但不能覆盖 `model`、`messages`、`stream`。
- 必须是 JSON 对象，否则保存时会提示错误并保留原值。

| 服务商 | 额外请求参数 |
|---|---|
| DeepSeek / 智谱 | `{"thinking":{"type":"disabled"}}`（默认值） |
| 通义千问（DashScope） | `{"enable_thinking":false}` |
| Gemini 3.x Flash | `{"reasoning_effort":"minimal","max_tokens":512}`（3.8 Flash 最低只能 `"low"`） |
| Gemini 2.5 Flash | `{"reasoning_effort":"none"}` |
| OpenAI 及其它不认识这些字段的服务商 | 留空 |

**Gemini**：API 地址填 `https://generativelanguage.googleapis.com/v1beta/openai`。Gemini 的 `max_tokens` 包含思考 token，默认的 80 可能在输出正文之前就用完，所以要像上表那样加上 `"max_tokens":512`。如果模型只返回了思考内容，或者输出被截断，插件会提示你关闭思考或调大 `max_tokens`。

### CORS 与 forwardProxy

默认由思源前端直接发起请求。如果浏览器因为 CORS 拦截了请求（常见于 Docker 部署、用浏览器访问思源的情况），请开启「通过内核 forwardProxy 转发」，改由思源内核通过 `/api/network/forwardProxy` 发出请求。

- 开启安全模式（SafeMode）时，内核 forwardProxy 会拒绝回环地址和内网地址。使用本地 LLM（`http://127.0.0.1:11434/v1`、`http://192.168.x.x…`）时请**关闭** forwardProxy，使用直连。
- 两种方式的请求超时都是 15 秒。

### 错误提示

预测失败时会弹出错误提示，例如：

- HTTP 状态码和服务端返回的信息
- 内核转发失败
- 请求超时
- 响应不是 JSON（通常是 API 地址填错了）
- 模型没有返回正文

提示中的 API Key 会显示为 `***`，过长的信息会被截断，同一条提示一分钟内最多显示一次。

## 自定义提示词

设置中可以修改：

- **系统提示词**：模型的角色与输出规则，比如文风、字数、语言。
- **用户消息模板**：可以使用以下变量（也支持全角花括号 `｛｛ ｝｝`）：
  - `{{title}}`：文档标题
  - `{{before}}`：前文
  - `{{current}}`：光标前的当前段落

  文档没有标题时，只含 `{{title}}` 一个变量的行会被删除。模板里没有 `{{current}}` 时，当前段落会自动附在末尾。
- **温度**：见上表。

两个文本框都有「恢复默认」按钮。留空保存，或者内容与默认值相同，都会记为「使用默认值」，以后内置提示词更新时会自动生效。

## 隐私说明

- **发送什么**：触发预测时，插件会把以下内容发送到你配置的 LLM 服务。请只连接你信任的服务。
  - 文档标题
  - 编辑器中已加载的、当前块之前的正文，最多「最大上下文字数」（默认 1500）个字
  - 光标前的当前段落
- **何时发送**：只有全局开关开启、当前文档已开启并且填写了 API Key 时才会发出请求。开启 forwardProxy 时，请求由运行思源内核的机器发出。
- **保存什么**：
  - 设置（包括明文的 API Key）保存在 `data/storage/petal/siyuan-plugin-ghostwriter/config.json`
  - 已开启文档的 ID 保存在同目录的 `docs.json`
  - 这两个文件都会随工作空间同步
- 插件不做任何统计上报，也没有其它网络访问。

## 开发

```bash
npm i
# 可选：直接构建到思源工作空间（.env.local 已被 git 忽略）
echo "SIYUAN_PLUGIN_DIR=<工作空间>/data/plugins/siyuan-plugin-ghostwriter" > .env.local
npm run dev        # 监听构建到 SIYUAN_PLUGIN_DIR（未设置时为 dist/）
npm run build      # 单次构建到 SIYUAN_PLUGIN_DIR（或 dist/）
npm run typecheck  # tsc --noEmit
npm run package    # 清空 dist/ 后构建并生成发布用的 package.zip
```

然后在 思源 → 设置 → 集市 → 已下载 中启用插件。
